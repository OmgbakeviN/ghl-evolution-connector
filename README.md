# WA Evolution Messaging

Backend Django permettant d'intégrer GoHighLevel avec Evolution API.

## État actuel

- Connexion PostgreSQL
- Installation OAuth GoHighLevel
- Stockage des tokens par Location
- Rafraîchissement automatique des tokens OAuth
- Endpoint de vérification du service

## Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- GoHighLevel API
- Evolution API
